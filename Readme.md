📚 Tecnologías y Conceptos Clave

A continuación se presenta un resumen de las tecnologías abordadas durante la materia:

🌐 HTML5 (HyperText Markup Language)

Es el lenguaje de marcado estándar utilizado para estructurar y desplegar el contenido de una página web. Permite definir elementos fundamentales como encabezados, párrafos, formularios, tablas y contenido multimedia mediante etiquetas semánticas.

🎨 CSS3 (Cascading Style Sheets)

Lenguaje de diseño gráfico utilizado para controlar la presentación, el formato y el estilo visual de los documentos escritos en HTML. Incluye el manejo de layouts responsivos (Flexbox, Grid), animaciones y diseño adaptable para múltiples dispositivos.

⚡ JavaScript (JS)

Lenguaje de programación interpretado, dinámico y multiparadigma. Es el motor principal para agregar interactividad, lógica del lado del cliente y manipulación del DOM (Document Object Model) en el navegador, además de permitir la ejecución en el servidor mediante Node.js.

🟦 TypeScript (TS)

Un superset tipado de JavaScript desarrollado por Microsoft que se compila a JavaScript plano. Introduce tipado estático, interfaces, clases y genéricos, facilitando la detección de errores en tiempo de compilación y mejorando el mantenimiento de aplicaciones a gran escala.

⚙️ NestJS

Un framework progresivo de Node.js para construir aplicaciones del lado del servidor (backend) eficientes, confiables y escalables. Está construido con TypeScript, utiliza conceptos de Programación Orientada a Objetos, Funcional y Reactiva, y adopta una arquitectura modular inspirada en Angular.

⚛️ React.js

Una biblioteca de JavaScript de código abierto desarrollada por Meta para construir interfaces de usuario (UI) interactivas y reutilizables mediante componentes. Se basa en un modelo de estado y en un DOM virtual (Virtual DOM) para optimizar el rendimiento y el renderizado.
